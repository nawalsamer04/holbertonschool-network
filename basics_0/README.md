# Networking Basics

## Description
This project introduces the fundamentals of networking. It focuses on the OSI model, types of networks, MAC and IP addresses, TCP and UDP, and network ports.

## Learning Objectives
- What is the OSI model
- How the OSI model is organized
- Types of networks (LAN, WAN, Internet)
- What is a MAC address
- What is an IP address
- What are TCP and UDP protocols
- What are network ports

- 0-OSI_model: Answers related to the OSI model
